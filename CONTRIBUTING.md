# Contributing

Thanks for helping keep this list accurate and useful. This is a neutral, community-maintained list of tools, methods, and resources for building a second brain. It is not a ranking and does not favor any product.

## What belongs here

Real, working tools, apps, methods, books, courses, creators, or communities related to personal knowledge management, note-taking, second brains, and personal AI. Both open-source and paid entries are welcome.

## How to add an entry

1. Fork the repo and edit `README.md`.
2. Add your entry to the right section, in alphabetical order.
3. Use this exact format:

   ```
   - [Name](https://example.com) - One neutral sentence describing it. `tag` `tag`
   ```

4. Keep the description to one factual sentence, under about 130 characters, ending with a period. No marketing words like "best" or "powerful".
5. Use only the tags in the table below.
6. Make sure the link works and points to the official site or the GitHub repo.
7. One entry per pull request where possible.

## Tags

| Tag | Meaning |
| --- | --- |
| `oss` | Open source |
| `selfhost` | Can be self-hosted |
| `local` | Local-first, your data stays on your device |
| `free` | Has a genuine free tier |
| `paid` | Paid only |
| `ai` | AI-native, built around AI |
| `mobile` | Has native mobile apps |

## Not accepted

Dead links, affiliate spam, products unrelated to second brains, and descriptions rewritten as marketing copy.
